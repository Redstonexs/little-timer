本次更新缩短结束提示音。

- **结束改为两次铃响**：约 2.2 秒的两次铃响，保留金属泛音与自然衰减，仍与时段提醒区分明显；提示比 v0.0.2 的四次连续铃响更简短。
- **更新发布流程依赖**：GitHub Actions 的检出与工件动作升级到当前版本。

下载 **LittleTimer.exe** 即可运行；**LittleTimer.exe.sha256** 为校验文件。可直接替换旧版 EXE，原有便携配置继续使用。

保持单 EXE、免安装、无额外运行库和音效文件。兼容目标为 Windows 7 及以上（32 位 / 64 位）；已做 PE 兼容检查，Windows 7 实机验证尚未完成。

铃响次数减少后峰值电平不变，整段平均电平比 v0.0.2 低约 1.3 dB；现场响度还取决于 Windows 音量、功放和扬声器，使用前可在「设置」中试听。
