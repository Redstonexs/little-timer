小小演讲计时器的首个版本，面向会场大屏使用。

- **单 EXE、免安装**：32 位原生 Windows 程序，无需额外运行库或音效文件。
- **大屏显示**：超大倒计时数字，支持独立投屏、全屏、暂停、继续和重置。
- **时段与结束提醒**：可设置多个剩余时间提醒点和循环提醒；内置柔和双音、清晰三音，可分别开关并试听。
- **超时提示**：到时变为红色，可选择停在零或继续显示超时时长。
- **便携配置**：默认仅运行 EXE；可选择在程序旁保存设置。

下载下方的 **LittleTimer.exe** 即可运行，**LittleTimer.exe.sha256** 为 SHA-256 校验文件。

默认演讲 20 分钟，剩余 5 分钟和 1 分钟时提醒。按 Space 开始 / 暂停，F11 全屏，F10 打开投屏。

本版本通过 Linux 核心测试、Windows 原生窗口验证及 PE 包装检查。兼容目标为 Windows 7 及以上（32 位 / 64 位）；Windows 7 实机验证尚未完成。
