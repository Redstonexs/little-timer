# 验证说明

本项目交付 `dist/LittleTimer.exe`，为面向 Windows 7 的 32 位便携程序。本页区分已经执行的测试与尚未执行的系统验证。

## 已执行

- Linux：GCC 15.2 的 AddressSanitizer / UndefinedBehaviorSanitizer 核心测试。
- Windows：Windows 11，系统版本 `10.0.26200.9168`，运行 MinGW-w64 交叉编译的 x86 EXE。
- GitHub Actions：Ubuntu 24.04 构建与 Windows Server 2022 原生验证；发布流程仅在两者通过后上传 EXE。
- 图形：真实 Win32 窗口与设置对话框、GDI+ 渲染，覆盖 1920×1080、1024×768、800×600、640×480 输出。
- 音频：真实 Windows 音频输出设备，使用静音 PCM 检查异步提交、打断播放、完成后释放与重新打开。
- 包装：通过 `scripts/verify-pe.py` 检查 PE32、GUI 子系统 6.1、ASLR / DEP、内置清单和系统 DLL 依赖。

计时与音效测试覆盖 92 项检查，包括暂停时的毫秒余量、倒计时取整、跨过提醒点、结束优先级、每轮只提醒一次、循环提醒、超时、输入边界、中文配置、音效平均电平、音量线性缩放、铃声衰减和防削波余量。

原生测试记录在 `build/windows-qa/windows-report.txt`，包含按钮和快捷键操作、独立投屏、全屏恢复、设置验证与取消、便携配置读写，以及连续重绘的 GDI 对象数量检查。实际界面截图位于 `docs/images/`。

## v0.0.2 回归验证

同一组四项刷新检查，在 v0.0.1 源码构建中全部失败，在 v0.0.2 中全部通过：

- 状态未变化时，不重复改写按钮文字。
- 开始计时只更新受影响的按钮文字。
- 倒计时继续走动，系统标题栏保持稳定。
- 按钮不先单独擦除背景，避免暴露中间帧。

另外检查按钮圆角边缘没有暗线、绘制不越过目标边界，以及连续 120 次窗口与按钮重绘不会积累 GDI 对象。

两版在 Windows 导出的 44.1 kHz / 16-bit / 单声道 PCM 样本，均使用相同的 75% 程序音量：

| 音效 | v0.0.1 平均电平 | v0.0.2 平均电平 | 变化 |
| --- | --- | --- | --- |
| 时段提醒 | −24.78 dBFS | −16.42 dBFS | +8.37 dB |
| 结束提醒 | −16.58 dBFS | −14.03 dBFS | +2.55 dB，改为 3.4 秒连续铃响 |

平均电平按全段 PCM 的 RMS 计算，包含起落与余音；它表示数字信号强度，不能代替会场声压测量。两种声音在 100% 程序音量下均保留峰值余量，未使用硬削波提升响度。

## v0.0.3 结束提示音

结束提示音由四次敲击改为两次，时长从 3.4 秒缩短到 2.2 秒，敲击间隔、金属泛音和余音衰减保持不变。同样以 75% 程序音量导出对比：

| 音效 | v0.0.2 平均电平 | v0.0.3 平均电平 | 变化 |
| --- | --- | --- | --- |
| 结束提醒 | −14.03 dBFS | −15.34 dBFS | −1.31 dB，敲击减少但峰值电平不变 |

核心测试仍为 92 项：铃声断言改按新的敲击位置检查，第二次敲击相对前一次余音高 2.49 倍，末段余音降到主体的 0.13 倍。因两次敲击后余音占比更高，全段平均电平不再适合直接与时段提醒比较，该项改为比较两种提示音的前 1 秒主体，结束提示仍高出约 15%。

交付产物的大小、SHA-256 和完整导入表，可重新生成：

```bash
python3 scripts/verify-pe.py dist/LittleTimer.exe --report build/pe-report.json
```

## 尚未验证

- Windows 7 实机 / 虚拟机启动、显示和音频播放。
- Windows 8 / 8.1 / 10 实机运行。
- 实际会场的双显示器布局、不同 DPI 组合，以及投影仪 / HDMI 扬声器音量。
- CMake / MSVC 构建路径。

Windows 7 兼容性目前由 x86 产物、6.1 子系统、旧版系统接口和系统 DLL 导入检查支撑。导入检查不能替代目标系统运行测试，也不对任意第三方音频驱动、精简系统或系统字体缺失作保证。

在目标 Windows 7 机器上，可直接复制 EXE，设置总时长 `0:10`、剩余提醒 `0:05, 0:02`，验证两种试听音、开始 / 暂停 / 继续、全屏、结束音及超时显示；无需安装运行库。
